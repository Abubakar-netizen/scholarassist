STRIDE Threat Model Safeguards

Mapping core SSD course security topics directly to our platform defenses:

Spoofing Identity: Demo credentials select a role in this prototype. Production authentication and server-side session validation are not implemented.
Tampering with Data: Input sanitization is demonstrated; application state is client-side and is not integrity-protected.
Repudiation: The in-memory demo audit stream records timestamps, actor, and role context; it is not a durable or tamper-proof log.
Information Disclosure: The student sees their own CNIC; the review queue shows it masked. These client-side checks do not protect data from a browser user.
Elevation of Privilege: Student and Scholarship Review Officer dashboards use separate role checks for protected actions.
