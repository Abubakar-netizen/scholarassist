STRIDE Threat Model Safeguards

Mapping core SSD course security topics directly to our platform defenses:

Spoofing Identity: Enforced through session validation, password complexity policies, and salted Argon2 hashing.
Tampering with Data: Prevented using cryptographic checksums (SHA-256) on student application state & parameter sanitization.
Repudiation: Guaranteed via append-only audit event streaming detailing timestamp, actor, IP address, and role context.
Information Disclosure: Data minimization applied. CNIC numbers masked, uploaded documents restricted by strict RBAC middleware.
Elevation of Privilege: Enforces Principle of Least Privilege across 4 distinct roles (Student, Officer, Univ Officer, Admin).
